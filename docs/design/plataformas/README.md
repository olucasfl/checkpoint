# Logos das plataformas

`apps/web/public/plataformas/*.svg` são **marcadores neutros provisórios** (pílula/quadrado cinza com o nome), **não** a marca
de ninguém. Cada logo oficial é marca registrada: entra sem redesenhar, seguindo as regras da plataforma.

## Steam (pendente)

- Fonte: pacote "Steam Brand Guidelines e Logos" da Valve, em `partner.steamgames.com/doc/marketing/branding`
  (`steam_brandGuidelines.pdf` + `steam_brandAssets.eps`; não há SVG oficial).
- O humano baixa o pacote, e o original (EPS + PDF, **sem editar**) vai em `docs/design/plataformas/steam/` com um `README.md`
  (data do download, versão, texto legal do ®). A conversão EPS → SVG **sem alterar o desenho** substitui
  `public/plataformas/steam.svg` e `steam-icone.svg`; o `PlataformaMarca` não muda.
- Regra da Valve: o logo fica sozinho, sem combinar com palavras ou símbolos; por isso a Steam usa só o logo, com o nome como texto acessível.
